# CMD on Lucid

A re-implementation of **Context-Matched Distillation** ([arXiv 2608.13391](https://arxiv.org/abs/2608.13391),
[nv-tlabs/cmd](https://github.com/nv-tlabs/cmd)) on [Lucid](https://github.com/lucid-official/lucid), running
the released [`nvidia/cmd`](https://huggingface.co/nvidia/cmd) checkpoints on Apple Silicon with Lucid's public
API only.

Work in progress.
